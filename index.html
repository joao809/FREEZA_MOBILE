06 / AVISOS DO SISTEMA

LEIA ANTES DE UTILIZAR:

1. A igualdade de tamanho não comprova que dois arquivos possuem a mesma estrutura interna.

2. O cabeçalho apresentado é uma leitura preliminar dos primeiros bytes, não uma validação completa do formato Unity.

3. O hash SHA-256 identifica o conteúdo exato de um arquivo. Se dois hashes forem diferentes, os conteúdos são diferentes.

4. A compatibilidade real depende da versão do Unity, da estrutura serializada e dos dados internos.

5. Esta ferramenta não promete compatibilidade total nem executa uma reconstrução estrutural dos arquivos.
